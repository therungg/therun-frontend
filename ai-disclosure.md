## AI Usage Disclosure

therun.gg has been in development since 2021. The vast majority of it was built before AI coding tools even existed. The backend, infrastructure, core logic, major features, design of major features were all built by hand.

That being said, since late 2025, Claude Code has been used for mostly repetitive and tedious tasks, such as:

- Write boilerplate and repetitive code
- Writing tests
- Small refactors
- Fixing easy bugs
- Small chores
- Maintenance tasks

Furthermore, when I can't find good solutions to some frontend tasks (I am a backend developer, my frontend skills are subpar), I ask Claude for assistance.

In the past, I have also had Claude refactor the styling of some pages. I've since stopped doing that because it looks worse than what I build myself with my very limited CSS knowledge.

I have limited time to work on the project, and using Claude Code for these tasks lets me spend that time working on the parts that are fun and important. Infra, backend and core features.

I read, review and adjust every change that is generated by Claude Code before it's committed. There's no vibe coding, and nothing is committed blindly/without manually testing.

I purposely added Claude to the contributor list to disclose this. I don't tag commits with Claude, since i check and push each one myself.

## What I never use AI for

I don't and will never use AI for any creative work on therun (or off it for that matter). This includes

- Images, art, graphics generation
- Copywriting
- Music
- Voice acting

If you have any questions or concerns, feel free to reach out. Always happy to talk.
